# Mini_Project1

Program ini digunakan untuk mendata aplikasi yang ada di HP. Ada 3 menu yang tersedia, yaitu tambah aplikasi, lihat aplikasi, dan keluar. Data aplikasi disimpan menggunakan list. Menu akan terus muncul selama program berjalan dan akan berhenti jika memilih menu keluar.
